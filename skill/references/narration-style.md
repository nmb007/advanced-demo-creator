# Narration style

- Talk about **what the user gets**, not what the cursor clicks.
  - Bad: "Now I click the Create course button."
  - Good: "From here you can create a new course in a few steps."
- About **150 words per minute**. Keep each scene to one idea.
- Use the **same product terms** throughout a long tour.
- Structure for long demos:
  1. Short intro scene (what we'll cover)
  2. Chapters with a one-line bridge between them
  3. Closing summary
- Avoid filler ("um", "as you can see", "simply", "just").
- Do not read credentials aloud; say "your administrator account".
- Match on-screen timing: if a form has three fields, the line should cover the whole form, not each keystroke.
